# Физическая модель

Ось z направлена вверх, неподвижное горизонтальное основание находится на z = 0.
Fz — заданная внешняя сила, приложенная к телу, без силы тяжести и реакции
основания. Положительный знак соответствует направлению вверх. Нагрузка не
выводится из тяги двигателя или характеристик какого-либо оборудования.

Уравнения: dz/dt = v; m·dv/dt = Fz(t) − m·g + N.
Односторонняя связь: z ≥ 0, N ≥ 0, z·N = 0.
В покое на основании z = v = 0 и N = m·g − Fz, пока Fz ≤ m·g.
При Fz > m·g удерживающая реакция невозможна: начинается свободное движение,
N = 0, dv/dt = Fz/m − g. Само равенство Fz = m·g не вызывает отрыва.
Время отрыва при непрерывном росте силы — граница интервала Fz > m·g.

CSV задаёт непрерывную кусочно-линейную силу внутри [t0, t1).
Вне этого интервала сила равна нулю. В t0 и t1 возможны скачки.
Решатель разделяет интегрирование по узлам CSV, границам воздействия и нулям
скорости. Последнее предотвращает пропуск двух пересечений основания внутри
одного большого шага: на каждом подынтервале высота монотонна.
Узкие импульсы поэтому не пропускаются даже при большом max_step.
В контакте положение вычисляется точно; в полёте основного метода используется SciPy solve_ivp
с обнаружением пересечения z = 0 сверху вниз. Расчёт заканчивается при первом
касании, сохраняя скорость непосредственно до удара.

z0 > 0 означает начальный полёт: факт отсутствия контакта есть, но момент
предшествующего отрыва неизвестен. z0 = 0, v0 > 0 означает отрыв в t = 0.
z0 = 0, v0 < 0 недопустимо: это уже начальный удар, которого модель не описывает.
Начальные условия задаются на t = 0. Отрицательная сила допустима.

Высота — зазор над основанием (max z), дополнительно выдаётся max z − z0.
Максимальная скорость вверх и максимальный модуль скорости — разные показатели.
Для ускорения также выдаются максимум со знаком и максимум модуля. Для RK45 экстремумы
скорости/высоты уточняются внутри каждого линейного участка независимо от
частоты вывода. Ускорения учитывают односторонние пределы на скачках силы;
ударное ускорение и импульс реакции не вычисляются. В строке касания ускорение
и скорость имеют значения непосредственно перед ударом, а состояние — касание.

Модель описывает только вертикальный перенос абсолютно твёрдого тела. Нет
упругости, вращения, частичного отрыва опор, опрокидывания, скольжения,
взаимодействия движущегося изделия с установкой, ударов и отскоков.
Общий отрыв означает отсутствие контакта в этой модели с одной степенью свободы.
Отсутствие касания до tmax не означает, что тело никогда не вернётся.
Результаты предназначены для предварительного исследования и не подтверждают
безопасность реального оборудования без независимой инженерной проверки.

В демонстрационном явном методе Эйлера z[k+1] = z[k] + h v[k],
v[k+1] = v[k] + h (F[k]/m - g). Шаг укорачивается на узлах нагрузки и отрыве.
При пересечении основания шаг обрезается в корне линейного интерполянта высоты;
скорость до удара интерполируется на том же шаге. Ниже основания вывод не идёт.
Отрыв по порогу силы определяется тем же законом, что в RK45. Первый шаг из
покоя может дать z = 0 при уже положительной скорости; для линейно нарастающей
от порога нагрузки возможна задержка движения на сетке. Это погрешность метода,
а не новое контактное допущение. Нужна проверка уменьшением шага.
Экстремумы Эйлера определяются по узлам, точность первого порядка.

Если касание не зарегистрировано, полное время полёта не определено. Отдельно
выводится длительность наблюдаемого свободного движения до конца интервала.
Максимальная сила определяется по всему заданному воздействию, остальные
максимумы - по рассчитанному движению до касания или tmax.

Проверка этапа 1: при Fz = 0 на основании N = mg и ускорение нулевое;
в полёте Fz = 0 даёт z = z0 + v0·t − g·t²/2. При Fz > mg реакция
в контакте стала бы отрицательной, поэтому требуется переход в полёт.
Противоречий в принятой односторонней модели не обнаружено.
