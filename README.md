# Вертикальная динамика конструкции

Приложение для предварительного расчёта вертикального движения твёрдого тела
на односторонней опоре. Русский пошаговый интерфейс, RK45 и явный метод Эйлера,
шесть графиков, сохранение вариантов JSON, результатов CSV и отчётов PDF.

## Запуск без Python

Откройте `dist/VerticalDynamics/VerticalDynamics.exe` двойным щелчком.
При переносе на другой компьютер копируйте **всю папку VerticalDynamics**:
рядом с EXE должна оставаться папка `_internal`. Установка Python не требуется.
Сборка предназначена для 64-разрядной Windows; установщик не нужен.

`run_gui.bat` запускает готовую сборку, если она есть, иначе использует `.venv`.

## Порядок работы

1. На вкладке **Массовые характеристики** введите массу. Начальные скорость
   и перемещение равны нулю, g = 9,81 м/с²; их можно изменить. Кнопка суммирования
   принимает только массы компонентов, которые вы явно включили в модель.
2. На вкладке **Внешнее воздействие** выберите постоянную силу либо таблицу/CSV.
   Укажите начало и продолжительность воздействия. Силу можно вводить в Н, кН
   или кгс; положительное направление вверх. График нагрузки показывается до расчёта.
3. На вкладке **Настройки и расчёт** задайте общее время, шаги и допуски.
   Основной метод — RK45. Для демонстрации выберите Эйлер и задайте его шаг.
4. Нажмите **Выполнить расчёт**. Отдельное окно содержит итоговую таблицу и
   шесть графиков: внешняя сила, реакция, ускорение, скорость, перемещение, контакт.
5. Сохраните результаты CSV, графики PNG или сформируйте PDF-отчёт.

К предыдущим этапам можно вернуться кнопкой «Назад» или выбором вкладки.
Десятичная запятая и точка поддерживаются в полях и ручной таблице.
Пустые обязательные поля перечисляются в сообщении; расчёт не запускается.
Изменение исходных данных сбрасывает прежние результаты. Если изменить данные
во время вычисления, устаревший результат не показывается.

В графиках доступны перемещение и прямоугольное масштабирование.
При движении курсора строка под графиком показывает время и вычисленное значение.
Отмечены начало/конец нагрузки, отрыв, максимум высоты и касание, если эти события
попали в рассчитанный интервал. Реакция при ударе не определена и не рисуется.

## Учебный пример

Откройте через **Открыть JSON** файл `examples/rectangular_case.json`.
Масса 10 кг, g = 9,81 м/с², искусственная сила 196,2 Н от 0,2 до 0,7 с.
Ожидаемые результаты RK45:

- Отрыв: 0,2 с.
- Максимальная высота: 2,4525 м при t = 1,2 с.
- Максимальная скорость вверх: 4,905 м/с.
- Первое касание: 1,907106781 с.
- Скорость перед касанием: −6,936717523 м/с.

Это искусственная нагрузка для проверки программы.

## Нагрузка и единицы

Для постоянной силы достаточно величины, начала и длительности.
Ручная таблица содержит по одной паре `время; сила` в строке, например:

```text
0; 0
0,5; 200
1; 0
```

Время ручной таблицы — секунды. Единица силы выбирается рядом с полем силы
и применяется ко всей таблице. При импорте CSV данные переводятся в Н,
в переключателе единиц устанавливается «Н».

CSV должен иметь ровно два столбца с явными единицами, без индекса строки:

```csv
time[s],Fz[N]
0,0
0.5,200
1,0
```

Допустимы время `s`, `ms`; сила `N`, `kN`, `kgf`.
1 кН = 1000 Н, 1 кгс = 9,80665 Н. CSV использует запятую как разделитель
и точку как десятичный знак. Необозначенные/неверные единицы отклоняются.
Внутри модели используются только СИ: кг, м, с, Н.

Время должно строго возрастать, значения должны быть конечными. Требуются
минимум две точки, покрывающие весь интервал воздействия. Экстраполяции нет.
Между узлами действует линейная интерполяция; вне [начало, конец) сила нулевая.
Скачки возможны на начале и конце воздействия. Повторяющиеся времена запрещены.

## Сохранение и воспроизводимость

**Сохранить JSON** записывает название, все физические параметры и настройки
обоих методов, единицы СИ и полную таблицу нагрузки. Файл не зависит от исходного
CSV. **Открыть JSON** восстанавливает вариант для дальнейшего редактирования.
Схема формата: `vertical-dynamics-case/1`.

Старые файлы `examples/config.json` и `examples/force.csv` поддерживаются:
на первой вкладке есть **Импорт прежней конфигурации JSON**, на второй —
**Загрузить CSV**. Старый JSON задаёт только параметры; новый хранит весь вариант.

Экспорт результатов создаёт отдельную подпапку с тремя файлами:

- `time_history.csv`: история движения в СИ, реакция, сила и состояние контакта.
- `summary.csv`: итоговые показатели и пояснения.
- `run_metadata.json`: параметры и исходная нагрузка для воспроизведения.

В итоговом окне и PDF отсутствующие значения показаны как «Не определено».
В CSV соответствующие ячейки пустые, а пояснение сохраняется отдельным столбцом.
PDF содержит название, дату UTC+03:00, исходные данные, модель, метод, результаты,
все графики, допущения, ограничения и полную таблицу нагрузки.

## Модель и методы

Ось z направлена вверх. Основание z = 0. Уравнения:

```text
dz/dt = v
m dv/dt = F(t) - mg + N
z >= 0, N >= 0, zN = 0
```

При покое на основании N = mg − F, пока F ≤ mg. Равенство F = mg
само по себе не вызывает отрыва. При превышении веса начинается полёт, N = 0.
Отрицательные силы увеличивают реакцию в покое либо ускоряют падение в полёте.

RK45 разбивает расчёт по узлам нагрузки и нулям скорости, что позволяет
обнаруживать первое пересечение основания даже при нескольких пересечениях
внутри крупного шага. Максимумы определяются независимо от сетки вывода.

Явный Эйлер использует `z_next = z + h*v`, `v_next = v + h*a`.
Шаг укорачивается на границах нагрузки и отрыва; касание уточняется на линейном
интерполянте перемещения. При старте из покоя первый шаг может иметь z = 0
и уже положительную скорость — особенность первого порядка. Экстремумы Эйлера
определяются по его сетке. Уменьшайте шаг и проверяйте сходимость с RK45.
Шаг вывода не является шагом интегрирования. Для Эйлера ограничено число шагов
(1 000 000); аналогично ограничено число регулярных строк вывода.

После отключения силы расчёт продолжается до первого касания либо заданного
времени. В последней строке касания скорость дана **до удара**, реакция неизвестна.
Последующие отскоки, ударные ускорения и напряжения не вычисляются.
Начальная высота > 0 означает уже начавшийся полёт с неизвестным прошлым моментом
отрыва. При z0 = 0 отрицательная скорость задаёт начальный удар и не допускается.
Максимумы относятся только к рассчитанному интервалу. Для незавершённого полёта
выводится наблюдаемая длительность; полное время до касания остаётся неизвестным.

Модель не определяет вращение, опрокидывание, деформации и частичный подъём опор.
**Отсутствие полного отрыва не исключает частичного подъёма отдельных опор
и не подтверждает безопасность конструкции.** Нагрузка должна быть независимо
обоснована пользователем; программа не вычисляет её из характеристик двигателей
или отделяющихся компонентов. Подробности: `docs/MODEL.md`.

## Запуск из исходников

Требуется Python 3.10+ с Tcl/Tk. В PowerShell из папки проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m vertical_dynamics
```

Точные версии проверенного окружения находятся в `requirements-tested.txt`.
Tkinter входит в обычную установку Python для Windows; PySide6 не требуется.

Консольный расчёт:

```powershell
.\.venv\Scripts\python.exe -m vertical_dynamics --case examples/rectangular_case.json --output output/example --report
.\.venv\Scripts\python.exe -m vertical_dynamics --case examples/rectangular_case.json --method Euler --euler-step 0.001 --output output/euler
.\.venv\Scripts\python.exe -m vertical_dynamics --config examples/config.json --force examples/force.csv --output output/legacy
```

CLI перезаписывает одноимённые результаты в выбранной папке. Используйте разные
папки для сохранения нескольких запусков. GUI создаёт подпапки автоматически.

## Проверка и сборка

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe tools/check_reference.py
.\.venv\Scripts\python.exe tools/check_gui.py
.\.venv\Scripts\python.exe tools/check_exe.py
```

`check_gui.py` требует обычного рабочего сеанса Windows. Тесты ядра, графиков
и отчётов запускаются без окна. Результаты проверки: `docs/VALIDATION.md`.

Для сборки запустите `build_exe.bat`; результат — `dist/VerticalDynamics`.
Необходимы PyInstaller и рабочий Tcl/Tk. Сборку следует выполнять из обычного
сеанса, поскольку песочница может скрыть Tcl/Tk от упаковщика.
